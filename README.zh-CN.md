# 随记 · Jot for Hermes

[English](README.md) · [使用说明](docs/GUIDE.zh-CN.md)

![随记：Hermes 可以读写的笔记，修改前核对版本，AI 的修改可以撤销](assets/readme/banner.png)

笔记就写在对话旁边。你允许了，Hermes 才能读写。

随记是装进 Hermes Desktop 的笔记本：从侧栏打开是完整页面，也可以停在对话右侧，边聊边记。和 Hermes 商量事情时，结论随手记下，过后也找得到。

![随记完整页面：置顶的周计划，带待办和表格](assets/readme/workspace.zh-CN.jpg)

## 写和整理

用起来就像常见的文档编辑器，不会 Markdown 也没关系：标题、列表、待办清单、引用、代码块、文字颜色和高亮都有。在空行输入“/”（中文输入法下打“、”也行），可以插入标题、列表、表格、分割线、图片或文件；熟悉 Markdown 的话，行首打 `#`、`-` 也能直接变成标题和列表。表格随时加行加列，列宽直接拖。图片和文件拖进来就好，图片显示在正文里，PDF 交给 Hermes 预览。

文件夹可用可不用，名字由你定。“最近”里是置顶笔记和最近改过的五条。搜索同时查标题和正文，有待办的笔记还会在列表里显示完成了几项。删掉的笔记先进回收站，永久删除之前都能恢复。对话里有值得留下的内容，选中后用“摘录选中的文字”，可以存成新笔记，也可以追加到已有笔记。

边写边自动保存。单条笔记可以导出为 Markdown、Word、PDF 或纯文本；一个文件夹或全部笔记可以打包成 ZIP，里面是 Word、PDF 或 Markdown 文件。导出的 PDF 内置中文字体。

从“排序与选项 → 导入笔记…”可以导入 Markdown、文本和 ZIP 文件；ZIP 里的文件夹，以及笔记链接到的图片和附件，会一起带进来。在 macOS 或 Windows 上打包的 ZIP，中文文件名也能正确识别。随记自己导出的 Markdown 导回时，文件夹、图片和附件都在；哪些内容不会带回，见[使用说明](docs/GUIDE.zh-CN.md#导入)。

## 和 Hermes 一起用

AI 协作默认关闭。在笔记列表底部打开“允许 AI 协作”，之后你提出要求，Hermes 就能查找、读取、新建和修改笔记，勾选待办，或者把笔记移到回收站。开关立即生效，不用重开对话；不想用了，随时关掉。开关关着的时候，Hermes 想读写笔记，随记都会拒绝，并告诉它开关在哪。随记也不会主动把笔记放进对话。

点输入框里的随记按钮，或者输入 `/jot`，笔记就停在对话右侧。工具栏和笔记菜单里都有“让 Hermes 看这条笔记”：它会先保存你正在写的内容，再把笔记引用放进输入框（没有输入框时复制到剪贴板），你接着说要做什么就行。

下图里，发布清单开在对话右侧，AI 协作已经打开。先用“让 Hermes 看这条笔记”把笔记交给 Hermes，再请它补充两项发布前要做的检查。它读完笔记，在清单末尾加了两条待办，右侧笔记随即更新，标上了“AI 修改”。

![对话右侧开着随记：Hermes 在“发布清单”末尾加了两条待办，笔记标上了“AI 修改”](assets/readme/sidebar.zh-CN.jpg)

不想要这两条？点“AI 修改”，再点“撤销修改”确认，笔记就回到这一轮修改之前的样子。

Hermes 连着做的几次修改算作一轮，会一起撤销，没法一处一处地撤。标题和所在文件夹也会一并恢复。也可以在笔记菜单里选“撤销 AI 的修改…”。你自己改过这条笔记以后，标记会消失，也就不能再撤销了。Hermes 新建的笔记没有更早版本可以退回，不想要就移到回收站。

## Hermes 能做什么，不能做什么

Hermes 改笔记时，一般只替换要改的那几处文字，或者在末尾追加，旁边的表格、图片和颜色原样保留。笔记末尾是待办清单时，新待办会接在后面。每次修改都以它刚读到的版本为准；如果你在这期间保存过，这次修改会被拒绝，不会盖掉你刚写下的内容。你正在这条笔记里打字时，Hermes 追加的内容会直接并进草稿，自动保存也不受影响。

如果整篇重写会丢掉 Markdown 表达不了的格式，比如图片、颜色、下划线，随记会拒绝，并让 Hermes 改用局部修改，或者先问你。

就算开着 AI 协作，Hermes 也不能：

- 查看回收站，或者永久删除笔记
- 撤销自己的修改，或者打开、关闭 AI 协作
- 导入笔记、添加附件、读取附件内容

## 笔记存在哪里

笔记只保存在运行 Hermes 的电脑上，具体在当前配置档案的数据目录里（默认配置档案对应 `~/.hermes/plugin-data/jot/`）。每个配置档案各有一套笔记和 AI 协作开关。卸载随记不会删除这个目录。随记不做云同步，也没有多人实时编辑；编辑界面只在 Hermes Desktop 里。

随记不需要另配 API Key，也不读取你的模型密钥，调用模型的是 Hermes 自己。笔记由一个小进程读写：每次请求时启动，做完就退出，不监听任何网络端口。

“允许 AI 协作”只管随记自己的工具。如果你另外给了 Hermes 文件或命令行权限，那是另一回事，它同样可能读到这个目录里的笔记。

## 安装

需要 Hermes 0.21.5 或更新版本，以及 Hermes Desktop。随记用 Hermes 正常安装时自带的 Node.js 运行，不用另装。

1. 在 Hermes Desktop 打开“技能与工具 → 插件”，在“插件目录”下点“浏览”，找到 Jot，点“+ Add to this Agent”（按钮文字是英文）。
2. 在“安装插件”对话框里保持“安装后启用智能体插件”打开，点“安装”。
3. 在插件列表 Jot 这一行打开“桌面”开关，侧栏就会出现“随记”。如果这一行显示“复制中…”，点“重新扫描”。
4. 想让 Hermes 读写笔记时，再到笔记列表底部打开“允许 AI 协作”。装好以后新开的对话里，Hermes 才能用上随记。

习惯用终端的话，运行 `hermes plugins install jot`，问是否启用时输入 `y`，再按第 3 步打开“桌面”开关。

之后如果随记提示后端没有启用，在 Jot 这一行重新打开 Agent 开关，或者运行 `hermes plugins enable jot`。

## 语言、主题和快捷键

随记跟着 Hermes 的界面语言走（设置 → 外观 → 语言），切换后马上生效。界面有简体中文、繁體中文、English、日本語、العربية、Русский、Français、Deutsch 和 Español，其他语言下显示英文。笔记保持自己的书写方向，阿拉伯语界面下的中文笔记照样从左往右排。主题同样跟随 Hermes，换主题或切换深浅模式都不用重开笔记。

快捷键在 Mac 上用 ⌘，在 Windows 和 Linux 上用 Ctrl，完整列表在“排序与选项 → 键盘快捷键”。“打开随记”“新建笔记”“摘录选中的文字”默认没有快捷键，可以在 Hermes 设置的“键盘快捷键”里搜索“随记”来绑定。
